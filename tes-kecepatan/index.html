Cara Dapat Hasil Akurat

  • Tutup aplikasi berat (download, update, streaming di perangkat lain) selama tes.
  • Dekat ke router — atau lebih akurat lagi via kabel LAN.
  • Tes 2–3x di jam berbeda (pagi vs malam) untuk gambaran adil.

Hasil Tes Artinya Apa?

  • 100+ Mbps — ngebut. Cukup untuk 4K multi-layar + WFH + gaming bareng.
  • 50–100 Mbps — lancar untuk streaming HD, WFH, dan gaming santai.
  • 20–50 Mbps — cukup browsing/sosmed; 4K dan multi-device bakal buffering.
  • Di bawah 20 Mbps — lemot untuk standar 2026. Waktunya upgrade atau pindah.

Butuh berapa untuk rumahmu? Hitung presisi dengan kalkulator Mbps. Curiga lemot karena dibatasi? Cek dengan simulator FUP.

Pertanyaan yang Sering Ditanyakan

Berapa lama tes kecepatan ini?

Sekitar 20–30 detik: pencarian server terdekat otomatis, pengukuran download ±10 detik, upload ±10 detik, plus ping.

Apakah hasil tes kecepatan akurat?

Tes memakai infrastruktur terbuka M-Lab (dipakai Google & regulator dunia) ke server terdekat otomatis. Hasil menggambarkan kondisi riil saat itu dan bisa bervariasi tergantung jam sibuk, WiFi vs kabel LAN, dan jumlah perangkat online bersamaan.

Apakah data saya direkam saat tes?

Ya — sesuai kebijakan data M-Lab, hasil pengukuran termasuk alamat IP dipublikasikan di arsip terbuka mereka untuk riset. Karena itu tes hanya berjalan setelah kamu mencentang persetujuan.

Kenapa hasil tes lebih kecil dari paket saya?

Penyebab umum: tes via WiFi (bukan kabel LAN), jarak ke router, banyak perangkat online bersamaan, atau jam sibuk. Coba tes ulang via kabel LAN dekat router. Kalau tetap jauh di bawah paket, hubungi sales untuk dicek.

Berapa kecepatan ideal untuk streaming 4K dan WFH?

Streaming 4K butuh 15–25 Mbps per TV, video call HD 3–4 Mbps, gaming butuh ping rendah. Untuk keluarga 4–6 orang, 250 Mbps adalah sweet spot — baca panduan 250 Mbps.
